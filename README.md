AtCoder is a programming contest site for anyone from beginners to experts. They hold weekly programming contests online.

This is a collection of my implementation of those problems in the C language. The reason I went with C is that:

1. It's a small language and want to improve in it
2. I want to implement most of the things myself that others take for granted with STL in C++ for example.
3. I feel superior over others who rely on already built in libraries and don't know how to implement things from scratch.
